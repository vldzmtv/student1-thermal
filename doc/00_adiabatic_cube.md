# Case 00 — Adiabatic Cube (A1)

## 1. Цель 

Цель — проверить корректность задания равномерного объёмного источника тепла в OpenFOAM и сопоставить численное решение с аналитическим результатом для задачи с постоянной скоростью нагрева.

Тест предназначен для проверки следующих аспектов:

- корректности знака объёмного источника тепла;
- соответствия размерности и величины источника заданной поглощённой мощности;
- правильности задания начальной температуры и граничных условий;
- корректности выполнения расчёта;
- извлечения минимальной и максимальной температуры из сохранённых полей;
- соответствия численного решения аналитической зависимости температуры от времени.

В рамках данного теста рассматривается равномерный нагрев адиабатического куба. Пространственное распределение температуры не предполагается: задача специально построена так, чтобы аналитическое решение имело простой линейный вид.

## 2. Расчётная модель

### 2.1. Геометрия и сетка

В качестве расчётной области используется куб со стороной 10 мм.

| Параметр | Значение |
|---|---:|
| Длина | 10 мм |
| Ширина | 10 мм |
| Высота | 10 мм |
| Объём | $1\cdot10^{-6}$ м³ |
| Количество ячеек | 1000 |
| Тип сетки | Структурированная гексаэдрическая |

Расчётная сетка строится утилитой `blockMesh`. После построения выполняется проверка сетки с помощью `checkMesh`.

### 2.2. Начальные и граничные условия

Начальная температура во всей расчётной области задаётся постоянной:

$$
T(\mathbf{x},0)=T_0=423.15\ \text{K}.
$$

На всех гранях куба используется условие `zeroGradient`. Таким образом, через границы расчётной области не происходит теплообмена.

Время расчёта составляет 1 с, шаг интегрирования по времени — 0.01 с. Сохранение результатов выполняется через каждые 0.1 с.

### 2.3. Теплофизические параметры и режим нагрева

Для расчёта используются параметры материала и режима REG-01 из пакета FIP-1.0.

| Параметр | Обозначение | Значение |
|---|---|---:|
| Мощность лазера | $P$ | 1200 Вт |
| Коэффициент поглощения | $\eta$ | 0.35 |
| Поглощённая мощность | $P_{\mathrm{abs}}$ | 420 Вт |
| Объёмная теплоёмкость | $\rho c_p$ | $3.6895\cdot10^6$ Дж/(м³·К) |
| Коэффициент температуропроводности | $D_T$ | $1.301\cdot10^{-5}$ м²/с |
| Начальная температура | $T_0$ | 423.15 К |

Поглощённая мощность определяется выражением:

$$
P_{\mathrm{abs}}=\eta P.
$$

Подстановка параметров режима даёт:

$$
P_{\mathrm{abs}}=0.35\cdot1200=420\ \text{Вт}.
$$

## 3. Задание объёмного источника тепла

### 3.1. Аналитическое представление

Для равномерного нагрева при отсутствии теплообмена через границы изменение температуры определяется уравнением:

$$
\rho c_p\frac{dT}{dt}=q_V,
$$

где $q_V$ — объёмная мощность источника тепла, Вт/м³.

При равномерном распределении поглощённой мощности по всему объёму:

$$
q_V=\frac{P_{\mathrm{abs}}}{V}.
$$

Следовательно:

$$
\frac{dT}{dt}=
\frac{P_{\mathrm{abs}}}{\rho c_p V}.
$$

В OpenFOAM источник задаётся через `scalarSemiImplicitSource` с режимом `volumeMode absolute`. Поэтому в качестве явного коэффициента используется величина:

$$
S_u=\frac{P_{\mathrm{abs}}}{\rho c_p}.
$$

Численное значение:

$$
S_u=
\frac{420}{3.6895\cdot10^6}
=
1.138365632199485\cdot10^{-4}.
$$

Размерность $S_u$ — К·м³/с. При использовании `volumeMode absolute` скорость нагрева равна $S_u/V$.

### 3.2. Настройка источника в OpenFOAM

В файле `system/fvOptions` используется следующий источник:

```cpp
uniformHeating
{
    type            scalarSemiImplicitSource;
    active          yes;

    scalarSemiImplicitSourceCoeffs
    {
        selectionMode   all;
        volumeMode      absolute;

        sources
        {
            T
            {
                explicit    1.138365632199485e-04;
                implicit    0;
            }
        }
    }
}
```

Источник применяется ко всем ячейкам расчётной области. Неявная составляющая равна нулю, поэтому источник полностью задаётся явным коэффициентом.

Для проверки точности в расчёте используется значение, вычисленное непосредственно из исходных параметров, без предварительного округления до $1.1384\cdot10^{-4}$.

## 4. Аналитическое решение

Поскольку источник тепла равномерный, начальная температура постоянная, а теплообмен через границы отсутствует, температура во всех точках области изменяется одинаково.

Аналитическая зависимость имеет вид:

$$
T(t)=T_0+
\frac{P_{\mathrm{abs}}}{\rho c_p V}t.
$$

Подставляя параметры расчёта:

$$
T(t)=423.15+
\frac{420}{3.6895\cdot10^6\cdot10^{-6}}t.
$$

Итоговая зависимость:

$$
\boxed{
T(t)=423.15+113.8365632199485t
}
$$

где температура выражена в К, а время — в секундах.

Таким образом, ожидаемая скорость нагрева составляет:

$$
\frac{dT}{dt}=113.8365632199485\ \text{К/с}.
$$

При $t=1$ с аналитическая температура равна:

$$
T(1)=536.9865632199485\ \text{К}.
$$

Это значение используется для проверки численного результата.

## 5. Контроль температуры и обработка результатов

### 5.1. Контроль минимальной и максимальной температуры

В `system/controlDict` подключён объект `fieldMinMax`:

```cpp
functions
{
    temperatureMinMax
    {
        type            fieldMinMax;
        libs            (fieldFunctionObjects);
        fields          (T);
        location        yes;
        writeControl    writeTime;
    }
}
```

Он вычисляет минимальное и максимальное значения поля температуры в моменты сохранения результатов.

Дополнительно используется скрипт `scripts/extract_temperature.py`. Он принимает путь к расчётному случаю, обрабатывает сохранённые временные директории и извлекает значения внутреннего поля `T`.

Для каждого момента времени формируются:

- `T_min_K` — минимальная температура среди внутренних значений поля;
- `T_max_K` — максимальная температура среди внутренних значений поля.

Эти значения вычисляются непосредственно по сохранённому полю температуры, а не считываются из текстового лога решателя. Результат записывается в CSV-файл.

Использование `fieldMinMax` обеспечивает дополнительную независимую проверку извлечённых значений.

### 5.2. Результат численного расчёта

Расчёт выполнен для временного интервала от 0 до 1 с с шагом интегрирования 0.01 с. Результаты сохранялись через каждые 0.1 с.

Всего получено 11 временных точек, включая начальный момент времени.

После повторного запуска с точным значением источника и параметром `writePrecision 12` получено:

| Параметр | Значение |
|---|---:|
| Начальная температура | 423.150000 К |
| Минимальная температура при $t=1$ с | 536.98656322 К |
| Максимальная температура при $t=1$ с | 536.98656322 К |
| Аналитическая температура при $t=1$ с | 536.9865632199485 К |
| Количество временных точек | 11 |

Минимальная и максимальная температуры совпадают в пределах точности сохранённых значений. Это соответствует ожидаемому равномерному нагреву расчётной области.

## 6. Проверка точности численного решения

### 6.1. Линейная аппроксимация

Для дополнительной проверки точности по всем 11 сохранённым временным точкам выполнена линейная аппроксимация методом наименьших квадратов:

$$
T_{\mathrm{fit}}(t)=at+b.
$$

Получены следующие параметры:

| Показатель | Значение |
|---|---:|
| Ожидаемый наклон | 113.8365632199485 К/с |
| Наклон МНК | 113.83656322000031 К/с |
| Свободный член МНК | 423.14999999999986 К |
| Коэффициент детерминации $R^2$ | 1.0000000000000000 |
| Максимальный модуль остатка МНК | $2.27\cdot10^{-13}$ К |

Остаток МНК определяется как разность между численным значением температуры и построенной регрессионной прямой:

$$
r_i=T_i-T_{\mathrm{fit}}(t_i).
$$

Он характеризует отклонение точек от линейной аппроксимации, но сам по себе не является погрешностью относительно аналитического решения.

### 6.2. Отклонение от аналитического решения

Для непосредственного сравнения с аналитической моделью вычислялось:

$$
\Delta T_i=
T_{\mathrm{num}}(t_i)-T_{\mathrm{analytical}}(t_i).
$$

Максимальное абсолютное отклонение за весь интервал расчёта составило:

$$
\boxed{
E_{\max}=5.15\cdot10^{-11}\ \text{К}
}
$$

Полученное отклонение подтверждает соответствие численного решения аналитической зависимости с высокой точностью.

В расчёте используется параметр `writePrecision 12`, определяющий точность записи численных полей. Поэтому при интерпретации результатов необходимо учитывать точность сохранения данных. В частности, при использовании `writePrecision 8` нельзя обоснованно заявлять о проверенной точности на уровне $10^{-14}$ К.

## 8. Проверка чувствительности и вырожденности задачи

### 8.1. Цель дополнительных экспериментов

Для проверки поведения расчётной модели выполнена серия дополнительных экспериментов. Их задача — установить, как изменение параметров источника тепла и коэффициента температуропроводности влияет на полученное температурное поле.

В качестве базового используется исходный случай Case 00. Для каждого дополнительного эксперимента создаётся отдельный расчётный случай, поэтому исходная конфигурация не изменяется.

Рассмотрены следующие варианты:

- увеличение коэффициента температуропроводности в $10^6$ раз;
- отключение источника тепла;
- изменение знака источника;
- увеличение источника в два раза;
- увеличение эффективной объёмной теплоёмкости в два раза.

### 8.2. Условия экспериментов

| Эксперимент | Изменение относительно базового случая |
|---|---|
| baseline | Исходная конфигурация |
| dt_x1e6 | $D_T$ увеличен в $10^6$ раз |
| source_off | Источник тепла отключён |
| source_negative | Знак источника изменён на отрицательный |
| source_x2 | Величина источника увеличена в 2 раза |
| rho_cp_x2 | Эффективная объёмная теплоёмкость увеличена в 2 раза |

В последнем эксперименте отдельное изменение $\rho c_p$ в используемой конфигурации `laplacianFoam` не задаётся. Эквивалентное воздействие при постоянной поглощённой мощности реализовано уменьшением коэффициента источника $S_u$ в два раза.

Для каждого варианта выполнялись построение сетки, проверка сетки, расчёт решателем, извлечение температур и формирование CSV-файла.

### 8.3. Результаты экспериментов

Для сравнения использовались ожидаемая аналитическая скорость нагрева, измеренный наклон линейной аппроксимации и конечная температура при $t=1$ с.

| Эксперимент | Ожидаемый наклон, К/с | Измеренный наклон, К/с | $T(1)$, К |
|---|---:|---:|---:|
| baseline | 113.83656322 | 113.836563220000 | 536.98656322 |
| dt_x1e6 | 113.83656322 | 113.836561827818 | 536.986561819 |
| source_off | 0 | 0.000000000000 | 423.15000000 |
| source_negative | -113.83656322 | -113.836563220000 | 309.31343678 |
| source_x2 | 227.67312644 | 227.673126438727 | 650.823126439 |
| rho_cp_x2 | 56.91828161 | 56.918281610000 | 480.06828161 |

Полученные результаты соответствуют ожидаемому поведению модели:

- при отключении источника температура практически не изменяется;
- при отрицательном источнике происходит охлаждение;
- при увеличении источника в два раза скорость нагрева также увеличивается в два раза;
- при увеличении эффективной объёмной теплоёмкости в два раза скорость нагрева уменьшается в два раза;
- увеличение коэффициента температуропроводности в $10^6$ раз практически не меняет результат: отличие конечной температуры от базового случая составляет около $1.40\cdot10^{-6}$ К.

Таким образом, зависимость температуры от источника тепла и эффективной объёмной теплоёмкости подтверждается дополнительными экспериментами. При этом влияние коэффициента температуропроводности в данной постановке практически не проявляется.

### 8.4. Объяснение вырожденности задачи

Полученный результат для эксперимента `dt_x1e6` связан с особенностью исходной постановки.

Уравнение, решаемое `laplacianFoam`, имеет вид:

$$
\frac{\partial T}{\partial t}
-
\nabla\cdot(D_T\nabla T)
=
S.
$$

В рассматриваемом случае:

- начальная температура одинакова во всех ячейках;
- источник тепла равномерный по всей расчётной области;
- на границах заданы условия `zeroGradient`;
- отсутствуют пространственные неоднородности температуры.

Следовательно, поле температуры остаётся пространственно равномерным:

$$
\nabla T=0.
$$

Поэтому диффузионный член равен нулю:

$$
\nabla\cdot(D_T\nabla T)=0.
$$

Из-за этого изменение коэффициента температуропроводности практически не влияет на результат. В данном тесте фактически проверяется временной отклик системы на равномерный источник тепла, а не перенос тепла в пространстве.

Для полноценной проверки теплопроводности необходимо использовать дополнительный расчётный случай с неоднородным начальным распределением температуры или неоднородными граничными условиями. В такой постановке появится ненулевой градиент температуры, и влияние коэффициента $D_T$ можно будет оценить непосредственно.

### 8.5. Интерпретация невязок решателя

В логах решателя для базового случая начальная относительная невязка на временном шаге близка к единице.

Это не означает, что ошибка температуры составляет 100%. Начальная невязка нормируется относительно начальной невязки линейной системы на текущем шаге. Поэтому значение `Initial residual = 1` само по себе является допустимым и не свидетельствует о некорректности расчёта.

Для базового случая конечная невязка на первом шаге составляет приблизительно $9.35\cdot10^{-12}$, а решение достигается за 6 итераций. При увеличении $D_T$ в $10^6$ раз количество итераций возрастает примерно до 31, что отражает изменение численных свойств линейной системы.

Следовательно, при оценке качества расчёта необходимо учитывать не только начальную невязку, но и конечную невязку, число итераций и соответствие полученного решения аналитической модели.

## 9. Итоговое заключение

Численное решение сопоставлено с аналитической зависимостью температуры от времени. Максимальное абсолютное отклонение составило $5.15\cdot10^{-11}$ К. Линейная аппроксимация по 11 временным точкам дала коэффициент детерминации $R^2=1.0$.

Дополнительная серия экспериментов подтвердила правильную реакцию модели на изменение величины и знака источника тепла, а также на изменение эффективной объёмной теплоёмкости. Одновременно выявлена вырожденность исходной постановки по отношению к диффузионному члену: при пространственно равномерном температурном поле градиент температуры равен нулю, поэтому коэффициент температуропроводности практически не влияет на результат.

Таким образом, Case 00 подтверждает корректность задания равномерного источника тепла и временного изменения температуры в выбранной постановке.
