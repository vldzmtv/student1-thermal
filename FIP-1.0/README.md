# FIP-1.0 -- Frozen Input Pack
# Laser cladding CAE, student tasks S1 / S2 / S3

Material: steel 45 / AISI 1045 (substrate), model austenitic stainless 316L (clad).
ALL DATA ARE MODEL (SYNTHETIC) OR FROM OPEN LITERATURE.
Requesting customer drawings, process sheets, measurements or material certificates is FORBIDDEN.

## Rules
1. Do not edit anything inside this pack. Copy it into your repo as received.
2. All exchange numbers are SI: m, s, K, kg, W, Pa. Column/key names carry units.
3. Canonical grids, times and masks are generated by grid/make_grid.py. Never re-derive them.
4. No communication with other students until week 8. Questions: supervisor, written issue.
5. A deliverable pack is accepted only if the corresponding selfcheck passes.

## Layout
material/    material cards (single source of truth for all three modules)
geometry/    model plate P01 and model ring R01
regimes/     REG-01 (plate), REG-02 (ring sector), REG-SERIES (parametric series)
tolerances/  ISO 286 IT grades, model allowance and stock criterion
probes/      fixed probe sets P01 (12), R01 (10), S2 subset (9)
grid/        CANONICAL grid / time / mask generator + OpenFOAM point lists
thermal/     make_thermal_ref.py (analytic fixture), compose_thermal.py (S1+S2)
check/       verify_fip.py + selfcheck_s1/s2/s3.py
scripts/     shared numerics: km, ovality, saho, stefan, map_thermal
schema/      meta.json schema, CSV column spec
templates/   canonical laser source fvOptions
doc/         OUTPUT_SPEC.md (the contract), ASSUMPTIONS.md

## Quick start
    python3 check/verify_fip.py                  # integrity + unit tests, must be all PASS
    python3 grid/make_grid.py P01                # grid_P01_points.csv, times_s1.csv, points_P01
    python3 grid/make_grid.py R01                # grid_R01_points.csv, times_ring.csv, points_R01
    python3 grid/make_grid.py mask POOL2D        # mask_POOL2D.csv, points_mask_POOL2D
    python3 thermal/make_thermal_ref.py P01 --out thermal_input/stage1_fixture
    python3 check/selfcheck_s1.py ../out/s1-p01-base-m02-v1

## Thermal input slot (S3)
stage1_fixture  -> analytic fixture (interface testing ONLY, no engineering conclusions)
stage2_own_cfd  -> your own conduction run (weeks 4-7)
stage3_composed -> S1+S2 composition, week 8, via thermal/compose_thermal.py
Switching stages must not change a single line of the mechanics code.

## Integrity
manifest.json holds sha256 of every file. Verify: python3 check/verify_fip.py
