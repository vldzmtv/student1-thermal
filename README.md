## Реализованные расчётные кейсы

### 00 — Нагрев адиабатного куба

Проверочный расчёт равномерного нагрева кубической области с использованием решателя `laplacianFoam`.

Основные параметры:
- Размеры расчётной области: 10 × 10 × 10 мм.
- Расчётная сетка: 10 × 10 × 10 ячеек (1000 ячеек).
- Начальная температура: 423.15 K.
- Мощность лазера: 1200 W.
- Коэффициент поглощения: 0.35.
- Поглощённая мощность: 420 W.
- Коэффициент температуропроводности: 1.301 × 10⁻⁵ м²/с.
- Граничные условия: `zeroGradient` на всех гранях.

Расчёт проверен по аналитической скорости нагрева и энергетическому балансу. Относительная погрешность составила менее 0.5%.

Результаты находятся в каталоге `results/`:
- `temperature.csv` — значения температуры во времени.
- `T_vs_time.png` — график изменения температуры.

## Установка и запуск

### 1. Подготовка OpenFOAM

Установить OpenFOAM.

После установки загрузить окружение OpenFOAM. Например:

```bash
source /opt/openfoam2406/etc/bashrc
```

Проверить доступность необходимых решателей:

```bash
which blockMesh
which checkMesh
which laplacianFoam
```

### 2. Подготовка Python

Из корневого каталога проекта создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установить зависимости из файла:

```bash
pip install -r env/pip-freeze.txt
```

### 3. Запуск расчёта

Перейти в каталог кейса:

```bash
cd cases/00_adiabatic_cube
```

Создать расчётную сетку:

```bash
blockMesh
```

Проверить сетку:

```bash
checkMesh
```

Запустить расчёт:

```bash
laplacianFoam
```

### 4. Обработка результатов

Вернуться в корневой каталог проекта:

```bash
cd ../..
```

Активировать виртуальное окружение, если оно ещё не активировано:

```bash
source .venv/bin/activate
```

Построить график температуры:

```bash
python3 scripts/plot_temperature.py
```

## Где найти параметры, результаты и логи

### Исходные параметры расчёта

Настройки кейса `00_adiabatic_cube` находятся в каталоге `cases/00_adiabatic_cube/`:

- `0/T` — начальная температура и граничные условия.
- `constant/transportProperties` — коэффициент температуропроводности.
- `system/blockMeshDict` — размеры расчётной области и параметры сетки.
- `system/controlDict` — настройки времени расчёта и решатель.
- `system/fvOptions` — параметры объёмного источника тепла.
- `system/fvSchemes` — численные схемы дискретизации.
- `system/fvSolution` — настройки решения уравнений.

### Численные результаты

В каталоге `results/`:

- `temperature.csv` — численные значения температуры во времени.
- `T_vs_time.png` — график изменения температуры.

### Логи выполнения

В каталоге `cases/00_adiabatic_cube/logs/`:

- `laplacianFoam.log` — полный журнал выполнения основного расчёта.

В каталоге `env/verification_cavity/`:

- `log.blockMesh` — журнал построения тестовой сетки.
- `log.checkMesh` — журнал проверки тестовой сетки.
- `log.icoFoam` — журнал тестового расчёта cavity.
