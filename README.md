## 2. Работа в WSL2

Основной вариант запуска проекта — WSL2 с Ubuntu и OpenFOAM v2406.

### 2.1. Клонирование репозитория

```bash
git clone https://github.com/vldzmtv/student1-thermal.git S1-work
cd S1-work
```

### 2.2. Загрузка окружения OpenFOAM

```bash
source /usr/lib/openfoam/openfoam2406/etc/bashrc
```

Проверить версию:

```bash
foamVersion
```

Ожидаемая версия — `v2406`.

### 2.3. Настройка Python

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

Активировать его:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
python -m pip install --upgrade pip
pip install -r env/pip-freeze.txt
```

Проверить установленные пакеты:

```bash
pip freeze
```

## 3. Работа через Docker

Альтернативный вариант запуска — контейнер `opencfd/openfoam-dev:2406`. Он позволяет использовать OpenFOAM v2406 без отдельной установки OpenFOAM в WSL2.

### 3.1. Создание контейнера

Команды выполняются из корневой директории репозитория на хостовой системе:

```bash
docker run -d \
  --name openfoam2406-s1 \
  -v "$PWD:/home/openfoam/S1-work" \
  -w /home/openfoam/S1-work \
  opencfd/openfoam-dev:2406 \
  sleep infinity
```

Параметры:
- `-v` — подключает локальную директорию проекта к контейнеру;
- `-w` — задаёт рабочую директорию внутри контейнера;
- `sleep infinity` — оставляет контейнер запущенным.

Локальные файлы проекта доступны внутри контейнера по пути `/home/openfoam/S1-work`.

### 3.2. Вход в контейнер

```bash
docker exec -it -u ubuntu openfoam2406-s1 bash
```

Загрузить окружение OpenFOAM:

```bash
source /usr/lib/openfoam/openfoam2406/etc/bashrc
```

Перейти в корневую директорию проекта:

```bash
cd /home/openfoam/S1-work
```

Проверить версию OpenFOAM:

```bash
echo "$WM_PROJECT_VERSION"
```

Ожидаемая версия — `v2406`.

### 3.3. Настройка Python

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

Установить зависимости:

```bash
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r env/pip-freeze.txt
```

Проверить установленные пакеты:

```bash
.venv/bin/python -m pip check
```

Если контейнер уже создан и запущен, повторно выполнять `docker run` не нужно. Для повторного входа используется команда `docker exec`.

## 4. Запуск расчёта

Перед запуском необходимо загрузить окружение OpenFOAM и убедиться, что создано Python-окружение в используемой среде — WSL2 или Docker.

### 4.1. Запуск

Из корневой директории проекта.

В WSL2:

```bash
./Allrun
```

В Docker:

```bash
./Allrun
```

Скрипт автоматически использует `.venv/bin/python`, если переменная `PYTHON` не задана. При необходимости путь к интерпретатору можно переопределить через переменную окружения `PYTHON`.

Скрипт последовательно выполняет:

1. Построение вычислительной сетки с помощью `blockMesh`.
2. Проверку сетки с помощью `checkMesh`.
3. Расчёт с помощью `laplacianFoam`.
4. Извлечение температурных данных.
5. Построение графика температуры.

Журналы выполнения сохраняются в `cases/00_adiabatic_cube/logs/`.

### 4.2. Очистка результатов

Для удаления сгенерированных результатов и подготовки случая к повторному запуску:

```bash
./Allclean
```

Скрипт удаляет временные директории времени, вычислительную сетку и сгенерированные файлы в `results/`. Исходные настройки расчёта сохраняются.

## 5. Обработка результатов

### 5.1. Извлечение температуры

Скрипт `scripts/extract_temperature.py` извлекает минимальную и максимальную температуру из поля `T` в сохранённых временных директориях OpenFOAM.

Результат сохраняется в CSV:

```text
results/temperature.csv
```

Формат:

| Столбец | Описание |
|---|---|
| `time_s` | Время расчёта, с |
| `T_min_K` | Минимальная температура, K |
| `T_max_K` | Максимальная температура, K |

### 5.2. Построение графика

Скрипт `scripts/plot_temperature.py` использует:

- `results/temperature.csv` — численные результаты;
- `FIP-1.0/material/steel_1045_v1.json` — параметры материала;
- `FIP-1.0/regimes/REG-01.json` — параметры технологического режима;
- `cases/00_adiabatic_cube/system/blockMeshDict` — геометрические параметры расчётной области.

По этим данным формируется аналитическое решение, которое сравнивается с результатами OpenFOAM.

Итоговый график сохраняется в: `results/T_vs_time.png`

График содержит два раздела:
- изменение температуры во времени для численного и аналитического решений;
- отклонение численного решения от аналитического.

Разрешение итогового изображения составляет 300 DPI.

## 7. Проверка FIP-1.0

Для проверки исходных данных FIP-1.0 используется скрипт:

```bash
python3 FIP-1.0/check/verify_fip.py
```

При использовании виртуального окружения:

```bash
.venv/bin/python FIP-1.0/check/verify_fip.py
```

Результат проверки сохраняется в:

```text
env/fip-verification.log
```

Ожидаемый итог успешной проверки:

```text
FIP RESULT: OK
```

Каталог `FIP-1.0/` является исходным набором данных и не изменяется в ходе расчётов.

## 9. Воспроизводимость

Для повторения расчёта необходимо:

1. Клонировать репозиторий.
2. Настроить окружение OpenFOAM v2406 одним из описанных способов.
3. Создать Python-окружение в используемой среде и установить зависимости из `env/pip-freeze.txt`.
4. Выполнить `./Allrun`.
5. Проверить полученные CSV-файл, график и журналы расчёта.
